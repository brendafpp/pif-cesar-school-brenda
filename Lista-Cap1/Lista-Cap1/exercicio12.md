## Questão 12

| Instrução | Status | Justificativa Teórica |
| a) `int a;` | **Correto** | Declara a variável `a` como um número inteiro (`int`). |
| b) `float b;` | **Correto** | Declara a variável `b` como um número de ponto flutuante (`float`). |
| c) `double float c;` | **Incorreto** | Não é possível utilizar `double` e `float` juntos na mesma declaração. |
| d) `unsigned char d;` | **Correto** | Declara `d` como caractere sem sinal (`unsigned char`). |
| e) `unsigned e;` | **Correto** | `unsigned` sem outro tipo é equivalente a `unsigned int`. |
| f) `long float f;` | **Incorreto** | `long float` não é um tipo válido em C. Para maior precisão, utiliza-se `long double`. |
| g) `long g;` | **Correto** | Declara `g` como um inteiro de tamanho `long` (`long int`). |
| h) `long double h;` | **Correto** | Declara `h` como um número de ponto flutuante de maior precisão (`long double`). |
